## Boundaries without a field in the port

- **nginx/openssl**: The artifact's isolated TLS bridge passes only copied buffers and numeric handles, so the port has no SP3 field (I10). The artifact's sp3_cases.csv for this boundary has 196 rows for the OpenSSL API as nginx calls it natively; the paper counts 5 fields and 11 with unknown expected domain. Which 16 of the 196 rows the paper means is not recorded anywhere in the artifact. If the ex_data pair of I6 is added, its pointer is a T object: manual registration in T.
